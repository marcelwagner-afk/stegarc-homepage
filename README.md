# STEGARC – Homepage

Statische Website von Marcel Wagner – STEGARC (Einzelunternehmen, Eppingen): Startseite, Impressum, Datenschutzerklärung.

- Keine externen Ressourcen, keine Cookies, kein Tracking. Die Überschriften-Schrift (Plus Jakarta Sans ExtraBold, SIL OFL 1.1) liegt in `assets/fonts/`, der Fließtext nutzt die Systemschrift.
- Veröffentlichung über GitHub Pages: Repository veröffentlichen, dann *Settings → Pages → Branch `main`, Ordner `/ (root)`*.
- Bei Änderungen an Anschrift, Kontakt oder Hosting Impressum und Datenschutzerklärung mitziehen (Stand-Datum unten anpassen).
